# *Project Description:*

The Prescription Pharmacy System is a web-based application designed to improve the process of managing prescriptions and pharmacy services. The system addresses the need for an organized and efficient way to manage prescriptions, medications, patients, and pharmacy operations.  

The intended users are patients and pharmacy staff (including pharmacists). Patients can use the system to view their active prescriptions, request refills, track the status of their requests, and see where to pick up their medication, while pharmacy staff can manage prescriptions, medication records, patient information, refill requests, and inventory.  

The main features of the system include prescription management, refill request processing, patient information management, medication and inventory management, refill status tracking with notifications, and pharmacy pickup management. The system is expected to allow authorized users to create, view, update, and manage prescription records while keeping information organized and accessible.  

The key functionality is to provide a centralized system that makes prescription and pharmacy management more efficient, reduces manual work, and helps users access accurate prescription and medication information.
