# Scenarios  

## *Scenario 1: Request a Prescription Refill*  
**Actor**: (Patient)  
A patient logs into the system, selects an active prescription, and submits a refill request. The system checks if a refill is due and sends the request to the pharmacy for processing.     

## *Scenario 2: Processing a Refill Order*  
**Actor**: (Pharmacy Staff)  
A pharmacy staff member views incoming refill requests, checks medication availability against inventory, and approves or rejects the request with a reason.    

## *Scenario 3: Tracking Order Status*  
**Actor**: (Patient)  
A patient checks the app to see whether their refill request is pending, approved, being prepared, or ready for pickup.  

## *Scenario 4: Low Inventory Alert*  
**Actor**: (Pharmacy Staff)  
The system detects that a medication’s stock has fallen below a set threshold and notifies pharmacy staff so they can reorder before patient requests are affected.  

## *Scenario 5: New Patient Registration*  
**Actor**: (Patient)  
A new patient creates an account, enters their basic information, and links an existing prescription record so they can begin requesting refills through the system.  

## *Scenario 6: New Prescription Entry*  
**Actor**: (Pharmacy Staff)  
A staff member issues a new prescription for a patient, or a staff member enters it into the system on the doctor's behalf. The prescription record is linked to the patient's account so future refill requests can be submitted.  

## *Scenario 7: Update Order Status*  
**Actor**: (Pharmacy Staff)  
A staff member updates the status of the approved refill request which is reflected in real time so the patient can track progress through the system.
